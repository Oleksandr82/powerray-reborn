1 Before you leave home

This is the only step that needs internet. Do it once, at home, before you go anywhere without WiFi/cellular data.
  1. Required Install Python 3 on this laptop (from python.org or the Microsoft Store), if not already installed.
  2. Required Double-click Setup-Offline.cmd in this folder. It automatically:
    • Creates a private, self-contained Python environment inside this folder (venv\).
    • Downloads and installs all the packages the cockpit needs into that environment.
    Wait for it to print "Setup complete!" before closing the window.
Once Setup-Offline.cmd finishes successfully, everything in this folder works fully offline — no internet or cell signal needed again, even on a different day or a different WiFi network. Start-Cockpit.cmd always uses this bundled environment automatically, so it won't be affected by other Python installs/updates on the laptop.
If you ever move this folder to a different laptop, or delete the venv folder, just re-run Setup-Offline.cmd once (with internet) before your next trip.

2 Unpacking at the water

  1. Take the PowerRay drone and its floating base station out of the case.
  2. Power on the base station (it floats on the water and relays WiFi to the drone).
  3. Power on the drone itself.
  4. Wait about 15–30 seconds for the base station's WiFi network to appear.

3 Connect your laptop to the drone's WiFi

On your Windows laptop, open WiFi settings and connect to the network named like:

PRA_Station_XXXXXX (the exact numbers vary per unit)

Windows may say "No internet" after connecting — that is completely normal and expected. Stay connected anyway; the drone doesn't need internet, only your laptop needs to be on the same WiFi network as the drone.
Default WiFi password: 1234567890 (factory default from the PowerVision user manual — try this first).
You may see two WiFi networks — which one to pick:
NetworkCreated byUse for
PRA_Station_xxxxxxMain base station (the floating buoy)Connect to this one. Drone control, navigation, camera/video — this is what the cockpit needs.
PSE_xxxxxxBuilt-in PowerSeeker sonar/fishfinder moduleSonar data only. Not needed for flying/camera. Sonar support in this cockpit is only partial, so you can ignore this network for normal use.

4 Start the cockpit

  1. Open this folder (erebus-io-powerray) in File Explorer.
  2. Double-click Start-Cockpit.cmd.
  3. A black window opens and checks everything automatically:
    • Confirms Python and the required packages are present.
    • Warns (but continues) if you're not yet on the drone's WiFi.
    • Starts the cockpit server in the background.
    • Opens your web browser automatically to the cockpit at http://localhost:5000.
You'll know it worked when your browser opens on its own and shows the PowerRay cockpit dashboard (attitude indicator, compass, battery, joystick, camera panel).
You can minimize the black window — just don't close it while flying. Closing it does not stop the cockpit (it keeps running in the background); use Stop-Cockpit.cmd when you're done (see step 6).

5 Using the cockpit

PanelWhat it does
Status pillShows FCU OK when connected to the drone's flight controller. If it says Disconnected, see Troubleshooting.
Attitude indicatorLive roll/pitch artificial horizon.
CompassLive heading (yaw).
BatteryVoltage, current, and percentage remaining.
Navigation controlARM/DISARM the drone, choose flight mode, and drive with the on-screen joystick or a connected gamepad.
CameraConnect to the camera, take photos, start/stop recording, toggle the viewfinder.
Live videoShows the underwater camera feed in the browser (click "Connect" first).
ParametersSearch and edit the 358 PX4 flight-controller parameters (advanced — only change these if you know what you're doing).
SonarAvailable at /sonar_ui — waterfall display (support is partial; may show demo data only).
Important — no GPS underwater: the map/position shown is estimated by dead-reckoning from a "Home" point you set, not from GPS (radio doesn't travel through water). It will drift the longer and farther you drive. Your real safety net is the floating base station and its physical tether — keep it in sight and reel the drone in if in doubt.
Camera conflict: only one app can talk to the camera at a time. If you also have the official Vision+ app open on a tablet, close it first before connecting the camera here.

6 Stop the cockpit

  1. Close the browser tab (optional — this alone does not stop the server).
  2. Double-click Stop-Cockpit.cmd in the folder.
  3. It will confirm "Cockpit stopped".

You can then power off the drone and base station as usual.

7 Troubleshooting

SymptomWhat to try
Status shows Disconnected / no FCU OKConfirm your laptop's WiFi is connected to PRA_Station_xxxxxx (not your home network). Confirm the drone is powered on. Wait 15–20s after connecting for the flight controller to respond.
Browser doesn't open automaticallyManually open a browser and go to http://localhost:5000.
Start-Cockpit.cmd shows a "no bundled venv" / Python errorThe one-time setup from Step 1 wasn't completed on this laptop while you still had internet. You'll need to return somewhere with internet and double-click Setup-Offline.cmd.
No camera / live videoClose the official Vision+ app on any phone/tablet — the camera only allows one connected client. Then click "Connect" in the Camera panel again.
Cockpit seems stuck / unresponsiveRun Stop-Cockpit.cmd, then Start-Cockpit.cmd again.
Something looks seriously wrong underwaterUse the Emergency Surface control in the Navigation panel, then locate the floating base station buoy and reel in the tether.
